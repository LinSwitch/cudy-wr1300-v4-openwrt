# Установка прошивки на Cudy WR1300 v4

🌐 [English version of this guide is available here (README_EN.md)](README_EN.md)

Инструкция рассчитана на **Cudy WR1300 v4** и описывает последовательность, проверенную автором видео. Не используйте образ для другой аппаратной ревизии.

> ⚠️ **Внимание:** прошивка роутера всегда связана с риском. Заранее ознакомьтесь с доступными способами восстановления устройства. Не отключайте питание во время прошивки.

## 1. Подготовка

1. Проверьте наклейку на нижней стороне роутера: должна быть указана ревизия **WR1300 V4.0**.
2. Подключите компьютер к роутеру Ethernet-кабелем.
3. Скачайте и разархивируйте с [официального Google Drive Cudy](https://drive.google.com/drive/folders/1BKVarlwlNxf7uJUtRhuMGUqeCa5KpMnj?usp=sharing) промежуточный образ, предназначенный для снятия проверки подписи. Выбирайте файл именно для v4 (`WR1300 V4.0.zip`).
Подробности: [Cudy OpenWrt Software Download](https://www.cudy.com/blogs/faq/openwrt-software-download)
4. Скачайте из раздела **[Releases](../../releases)** этого репозитория пользовательскую сборку `*-squashfs-sysupgrade.bin`.

## 2. Установить промежуточную прошивку Cudy

1. Откройте веб-интерфейс заводской прошивки Cudy (по умолчанию `192.168.10.1`).
2. Откройте раздел обновления прошивки (Дополнительные настройки → Система → Прошивка), выберите скачанный промежуточный образ и подтвердите обновление.
3. Дождитесь полного завершения процесса и перезагрузки роутера. Не отключайте питание.

*После установки промежуточного образа веб-интерфейс OpenWrt будет доступен по адресу `http://192.168.1.1`. Пароль после прошивки пустой, просто нажмите Enter.*

## 3. Установить пользовательскую сборку OpenWrt

1. В веб-интерфейсе промежуточного OpenWrt откройте **System → Backup / Flash Firmware**.
2. Выберите **Flash new firmware image**.
3. Укажите файл `*-squashfs-sysupgrade.bin`, скачанный из раздела Релизов этого репозитория.
4. **Обязательно снимите отметку сохранения настроек (*Keep settings*)**.
5. Подтвердите прошивку и дождитесь завершения перезагрузки.

После загрузки войдите в новый веб-интерфейс. При первом запуске пользовательской сборки настройте систему заново.
